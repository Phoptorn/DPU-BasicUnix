# คู่มือการใช้งาน Unix เบื้องต้น (Basic Unix Tutorial)

คู่มือนี้จัดทำขึ้นเพื่อสอนการใช้งานคำสั่งพื้นฐานในระบบปฏิบัติการ Unix/Linux ซึ่งเป็นทักษะสำคัญสำหรับนักพัฒนาซอฟต์แวร์ ผู้ดูแลระบบ และผู้ที่สนใจใช้งาน Command Line

---

## 1. What's Unix? (Unix คืออะไร?)
**Unix** คือระบบปฏิบัติการ (Operating System) ชนิดหนึ่งที่ถูกพัฒนาขึ้นมาตั้งแต่ยุค 1970s มีจุดเด่นคือรองรับผู้ใช้งานหลายคนพร้อมกัน (Multi-user) และทำงานได้หลายโปรแกรมพร้อมกัน (Multi-tasking) 
ปัจจุบัน Unix เป็นรากฐานของระบบปฏิบัติการยอดนิยมมากมาย เช่น **Linux** (Ubuntu, CentOS) และ **macOS** การเรียนรู้คำสั่ง Unix จึงสามารถนำไปประยุกต์ใช้ได้กว้างขวางมาก

---

## 2. คำสั่งแสดงรายชื่อไฟล์ (`ls`)
คำสั่ง `ls` (List) ใช้สำหรับแสดงรายชื่อไฟล์และโฟลเดอร์ในไดเรกทอรีปัจจุบัน
*   `ls` : แสดงรายชื่อไฟล์และโฟลเดอร์แบบปกติ
*   `ls -a` : แสดงไฟล์ทั้งหมด รวมถึง "ไฟล์ซ่อน" (ไฟล์ที่ชื่อขึ้นต้นด้วยจุด `.`)
*   `ls -l` : แสดงรายละเอียดของไฟล์ (สิทธิ์การเข้าถึง, เจ้าของ, ขนาด, วันที่แก้ไข)
*   `ls -al` (หรือ `ls -la`) : นำ `-a` และ `-l` มารวมกัน คือแสดงรายละเอียดของไฟล์ทั้งหมดรวมถึงไฟล์ซ่อนด้วย

---

## 3. การสร้างโฟลเดอร์ (Create directory)
ใช้คำสั่ง `mkdir` (Make Directory) ตามด้วยชื่อโฟลเดอร์ที่ต้องการสร้าง
```bash
mkdir my_folder
mkdir folder1 folder2 folder3  # สร้างหลายโฟลเดอร์พร้อมกัน
```

---

## 4. การเปลี่ยนโฟลเดอร์ (Changing to a different directory)
ใช้คำสั่ง `cd` (Change Directory) เพื่อย้ายเข้าไปยังโฟลเดอร์ที่ต้องการ
```bash
cd my_folder
cd /var/www/html  # ย้ายไปยัง path ที่ระบุแบบเต็ม (Absolute Path)
```

---

## 5. โฟลเดอร์ปัจจุบัน (`.`) และ โฟลเดอร์แม่ (`..`)
ใน Unix จะมีสัญลักษณ์พิเศษ 2 ตัวที่ใช้แทนโฟลเดอร์:
*   `.` (จุดเดียว) หมายถึง **โฟลเดอร์ปัจจุบัน** (Current directory) มักใช้เวลาสั่งรันโปรแกรม เช่น `./script.sh`
*   `..` (สองจุด) หมายถึง **โฟลเดอร์ชั้นนอก** หรือโฟลเดอร์แม่ (Parent directory)
```bash
cd ..      # ถอยกลับไปโฟลเดอร์ชั้นนอก 1 ระดับ
cd ../..   # ถอยกลับไป 2 ระดับ
```

---

## 6. โฟลเดอร์บ้าน (Home directory)
**Home directory** คือโฟลเดอร์หลักของผู้ใช้งานแต่ละคน สัญลักษณ์ที่ใช้แทน Home คือเครื่องหมาย Tilde (`~`)
```bash
cd ~       # กลับไปที่ Home directory ทันที
cd         # พิมพ์ cd เปล่าๆ ก็เป็นการกลับ Home เช่นกัน
cd ~/Music # เข้าไปที่โฟลเดอร์ Music ที่อยู่ใน Home
```

---

## 7. การคัดลอกและย้ายไฟล์ (Copying and moving files)
*   **คัดลอก (`cp`)**: ย่อมาจาก Copy
    ```bash
    cp file1.txt file2.txt     # ก๊อปปี้ file1.txt เป็นชื่อ file2.txt
    cp file1.txt my_folder/    # ก๊อปปี้ไฟล์ไปไว้ในโฟลเดอร์
    cp -r folder1/ folder2/    # ก๊อปปี้ทั้งโฟลเดอร์ (ต้องมี -r)
    ```
*   **ย้าย / เปลี่ยนชื่อ (`mv`)**: ย่อมาจาก Move
    ```bash
    mv oldname.txt newname.txt # เปลี่ยนชื่อไฟล์
    mv file.txt my_folder/     # ย้ายไฟล์ไปที่โฟลเดอร์อื่น
    ```

---

## 8. การลบไฟล์และโฟลเดอร์ (Removing files and directories)
**ระวัง:** การลบใน Unix จะไม่ลงถังขยะ (Recycle Bin) ลบแล้วลบเลย
*   `rm` (Remove) : ใช้ลบไฟล์
    ```bash
    rm file.txt
    ```
*   `rmdir` (Remove Directory) : ใช้ลบโฟลเดอร์ **ที่ว่างเปล่าเท่านั้น**
*   `rm -r` (Recursive) : ใช้ลบโฟลเดอร์และข้อมูลทั้งหมดที่อยู่ข้างใน
    ```bash
    rm -r my_folder
    ```

---

## 9. การอ่านเนื้อหาในไฟล์ (Display the contents of a file)
*   `cat` : แสดงเนื้อหาทั้งหมดของไฟล์ออกมาบนหน้าจอทีเดียว
    ```bash
    cat log.txt
    ```
*   `less` หรือ `more` : ค่อยๆ แสดงเนื้อหาทีละหน้า (กด Spacebar เพื่อเลื่อน, กด `q` เพื่อออก)
*   `head` : แสดงเนื้อหา 10 บรรทัดแรก
*   `tail` : แสดงเนื้อหา 10 บรรทัดสุดท้าย (หากใช้ `tail -f` จะแสดงข้อมูลที่อัปเดตแบบ Real-time)

---

## 10. การเบี่ยงเบนทิศทางข้อมูล (Redirecting)
ใช้ควบคุม Output ที่จะแสดงบนจอ ให้ไปลงในไฟล์แทน
*   `>` : **เขียนทับ** (Overwrite) ลงในไฟล์ หากไม่มีไฟล์จะสร้างใหม่
    ```bash
    echo "Hello World" > hello.txt
    ```
*   `>>` : **เขียนต่อท้าย** (Append) ลงในไฟล์
    ```bash
    echo "More text" >> hello.txt
    ```
*   `<` : นำข้อมูลจากไฟล์ไปเป็น Input ให้คำสั่ง

---

## 11. ท่อส่งข้อมูล (Pipes `|`)
ใช้เครื่องหมาย `|` (Pipe) เพื่อนำผลลัพธ์ (Output) ของคำสั่งแรก ไปเป็นข้อมูลนำเข้า (Input) ให้คำสั่งถัดไป
```bash
ls -l | less         # ดูรายชื่อไฟล์แบบละเอียด โดยค่อยๆ เลื่อนดูทีละหน้า
cat log.txt | grep "Error" # อ่านไฟล์ log แล้วกรองหาเฉพาะบรรทัดที่มีคำว่า Error
```

---

## 12. สิทธิ์ของไฟล์ (File system security / Access rights)
เมื่อใช้คำสั่ง `ls -l` คุณจะเห็นสิทธิ์ของไฟล์ (เช่น `rwxr-xr--`) แบ่งเป็น 3 กลุ่ม:
1.  **User (u)** : เจ้าของไฟล์
2.  **Group (g)** : กลุ่มของเจ้าของ
3.  **Others (o)** : คนอื่นๆ ทุกคน

**ประเภทของสิทธิ์:**
*   `r` (Read) = อ่านได้ (ค่าตัวเลข = 4)
*   `w` (Write) = แก้ไข/ลบได้ (ค่าตัวเลข = 2)
*   `x` (Execute) = รันโปรแกรมได้ (ค่าตัวเลข = 1)

**การเปลี่ยนสิทธิ์ (`chmod`)**
ใช้ตัวเลขรวมกัน (เช่น 4+2+1 = 7 คือทำได้ทุกอย่าง)
```bash
chmod 755 script.sh  
# 7 (u) = rwx (4+2+1) เจ้าของทำได้ทุกอย่าง
# 5 (g) = r-x (4+1) กลุ่มอ่านและรันได้ แต่แก้ไม่ได้
# 5 (o) = r-x (4+1) คนอื่นอ่านและรันได้ แต่แก้ไม่ได้
```

## 13. Unix Cheat Sheet (สรุปคำสั่ง)

| คำสั่ง | อธิบายสั้นๆ |
|---|---|
| `pwd` | ดูว่าตอนนี้เราอยู่โฟลเดอร์ไหน (Print Working Directory) |
| `ls` / `ls -al` | ดูรายชื่อไฟล์ในโฟลเดอร์ |
| `cd <path>` | เปลี่ยนโฟลเดอร์ |
| `mkdir <name>` | สร้างโฟลเดอร์ใหม่ |
| `touch <file>` | สร้างไฟล์เปล่าๆ ใหม่ 1 ไฟล์ |
| `cp <src> <dest>` | ก๊อปปี้ไฟล์ |
| `mv <src> <dest>` | ย้าย หรือ เปลี่ยนชื่อไฟล์ |
| `rm <file>` | ลบไฟล์ |
| `rm -r <folder>` | ลบโฟลเดอร์และของข้างในทั้งหมด |
| `cat <file>` | อ่านไฟล์ |
| `grep <word>` | ค้นหาคำในข้อความหรือไฟล์ |
| `chmod <num>` | เปลี่ยนสิทธิ์การเข้าถึงไฟล์ |
| `clear` | ล้างหน้าจอ |
| `man <command>` | เปิดคู่มือของคำสั่งนั้นๆ (เช่น `man ls`) |
